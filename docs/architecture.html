Factory Inventory Management System

Architecture overview: a Vue 3 single-page app talks to a FastAPI backend over JSON. All data is loaded into memory from JSON files when the server starts. There is no database and no authentication.

Data flow: changing a filter

What happens when a user picks "Tokyo" in the warehouse filter on the Orders page.

  1. User picks a filterFrontend
    FilterBar.vue is bound to selectedLocation from useFilters().
  2. Shared state updatesFrontend
    The filter refs live at module level, so every view sees the same value. There is no Pinia or Vuex.
  3. View watcher refetchesFrontend
    The view calls api.getOrders(getCurrentFilters()). Location maps to warehouse, period maps to month.
  4. api.js builds the queryFrontend
    Filters set to "all" are left out, giving GET /api/orders?warehouse=Tokyo.
  5. Filters run in PythonBackend
    apply_filters() then filter_by_month() run list comprehensions over the in-memory orders list.
  6. Data read from memoryData
    No disk or database access per request. The lists were filled from JSON at startup.
  7. Response validatedBackend
    response_model=List[Order] checks the shape and strips fields not in the model.
  8. UI re-rendersFrontend
    The JSON goes into a ref. computed() properties derive totals and chart points, formatted in USD or JPY by locale.

Quarters are hardcoded in QUARTER_MAP for 2025 only. A month filter is a substring match on order_date.
Language switching (useI18n) is client-only. Picking Japanese also converts money to JPY at a fixed rate of 150.

Known gaps

Places where the frontend and backend don't match.

Tasks API is missingApp.vue calls /api/tasks (GET, POST, PATCH, DELETE) through api.js. The backend has no such route, so only the mock user's built-in tasks appear.
Purchase orders API is missingapi.js defines createPurchaseOrder and getPurchaseOrderByBacklogItem. The backend has the Pydantic models but no routes.
Backlog page is unreachableviews/Backlog.vue exists but isn't registered in the router in main.js.
